3. 确认是否使用了拼多多平台的专用面单（如拼多多单号格式），若使用非拼多多单号格式（如普通快递单号），需更换为拼多多平台的单号才可以。

    【补充说明】：手工发货时，若需将单号回传至拼多多店铺后台，必须使用拼多多平台的专用面单。否则，系统无法正确识别和回传单号，导致发货失败。建议在发货前确认单号为拼多多的单号，且单号的格式是否正确。

【问题现象】：在导入客户表格时，系统提示“打印失败，原因：业务服务错误，联系方式只能为数字或者空格或者-”，导致多笔订单无法成功打印。错误提示在打印失败弹窗中明确显示。
【原因分析】：表格导入失败是因为发件人信息（特别是“发件人手机”字段）格式不完整或不符合系统要求。系统要求“联系方式”字段内容必须为数字、空格或连字符“-”，若包含其他字符或格式错误，会导致解析失败并触发该错误提示。

2. 若“发件人手机”列存在非标准格式数据，需在表格中手动修正或清理无效数据。
3. 同时检查“发件人姓名”“发件人单位（店铺）”等字段是否完整填写，确保发件人信息完整。
4. 修正表格后，重新导入并尝试打印。

    【补充说明】：建议在导入前先预览表格数据，确认所有字段格式符合系统要求，避免因格式错误导致批量导入失败。

【问题标题】：菜鸟打印组件因缺少 SimHei 字体导致打印失败，提示“the font SimHei can not display ●”
【所属平台】：菜鸟打印（通用）
【问题现象】：使用菜鸟打印组件打印时，系统弹出错误提示：“com.cainiao.print.base.exception.MessageException: the font SimHei can not display ●”，打印任务失败。错误界面显示“文本绘制异常”，并提示“SimHei 字体无法显示 ●”符号。
【原因分析】：菜鸟打印组件在渲染打印内容时，尝试使用 SimHei 字体显示“●”符号，但系统未安装该字体或组件未识别该字体，导致字体缺失异常。
【解决方案】：

1. 优先：安装 SimHei 字体到系统
    * **Windows**：从其他电脑复制 `SimHei.ttf` 文件，粘贴到 `C:\Windows\Fonts\` 目录，重启菜鸟打印组件。
    * **Linux/macOS**：手动下载 `SimHei.ttf`，放到系统字体目录（如 Linux 的 `/usr/share/fonts/`），执行命令 `fc-cache -fv` 刷新字体缓存，重启菜鸟打印组件。
2. 备选：替换为其他支持的中文字体
    * 修改打印组件的字体配置文件，将字体设置为系统已有的中文字体：
        * Windows：`Microsoft YaHei`（微软雅黑）、`SimSun`（宋体）
        * Linux/macOS：`WenQuanYi Zen Hei`（文泉驿正黑）、`Noto Sans CJK SC`
3. 临时：移除或替换特殊符号
    * 将打印模板或内容中的 `●` 符号替换为其他兼容符号，如 `·` 或 `-`，避免触发字体缺失问题。

【问题标题】：库存货品中关联的商品有误，如何解绑并重新关联正确商品规格
【所属平台】：通用
【问题现象】：在库存货品中发现关联的商品规格有误，需要解除当前错误关联，重新绑定正确的商品规格。
【原因分析】：商品与库存货品的关联关系错误，需通过解绑操作解除现有绑定，再重新建立正确的关联关系。
【解决方案】：
方案一：单个解绑操作

1. 进入【库存管理】→【库存货品】界面。
2. 在列表中找到需要解绑的货品，点击右侧【更多】按钮。
3. 在弹出的菜单中选择【解除关联】选项。
4. 解绑成功后，回到商品管理界面，找到对应商品，展开规格，重新绑定正确的库存货品。

方案二：批量解绑操作（适用于多个商品）

1. 进入【商品管理】界面。
2. 使用筛选条件（如“已绑定库存”）筛选出需要解绑的商品。
3. 选中商品后，点击【批量解绑库存商品】按钮。
4. 解绑成功后，回到商品管理界面，展开商品规格，重新绑定正确的库存货品。
    【图片信息摘要】：
    ![库存货品界面解绑操作](https://pic.fengsutb.com/knowledge/1764678749526_4pwi3b15b9.png)
    ![商品管理界面筛选已绑定库存商品](https://pic.fengsutb.com/knowledge/1764678752327_cuclexj31ke.png)
    ![商品管理界面绑定库存货品](https://pic.fengsutb.com/knowledge/1764678868290_usdi8j2conh.png)
    【补充说明】：单个解绑操作适用于少量商品，操作简单直接；批量解绑操作适用于需要同时处理多个商品的情况，效率更高。解绑后需及时重新绑定正确的商品规格，避免影响库存管理。

【问题标题】：订单打印多单号如何回收指定单号
【所属平台】：通用
【问题现象】：系统中一个订单打印了多个快递单号，导致单号重复，需要回收其中一个或多个错误打印的单号。
【原因分析】：系统支持回收已打印但未发货的错误单号，但已发货订单的单号已回传后台，回收操作仅在系统内生效，不影响店铺后台数据，因此不建议对已发货订单回收单号。
【解决方案】：

1. 进入【打单发货】页面，切换至【待发货】标签页。
2. 在订单列表中找到需要处理的订单，点击快递单号右侧的垃圾桶图标。
3. 在弹出的回收确认窗口中，勾选需要回收的单号，点击【确定回收选中的单号】按钮。
4. 回收完成后，记得将对应的快递单据物理撕毁，避免误发货。
    【图片信息摘要】：
    ![代发货界面回收单号操作](https://pic.fengsutb.com/knowledge/1764723465978_clgngu6wg5d.png)
    ![回收确认弹窗界面](https://pic.fengsutb.com/knowledge/1764723471511_gk2438e9by.png)
    【补充说明】：

* 仅支持回收【待发货】状态下的错误打印单号。
* 已发货订单的单号已同步至平台后台，回收操作仅在系统内生效，不推荐操作，以免造成数据混乱。
* 回收后务必物理销毁错误单号，防止误发。
